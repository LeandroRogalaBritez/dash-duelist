# Dash Duelist

Protótipo de estudo para um jogo de duelo em **Godot Engine 4.7**, focado em movimentação ágil e um mecanismo central de *dash*.

> ⚠️ Projeto em estágio inicial

## 🎮 Sobre o jogo

Dash Duelist é um jogo de combate/duelo onde a movimentação rápida e o timing do dash são a base da jogabilidade.
## 🕹️ Controles

| Ação | Tecla |
|---|---|
| Mover para cima | `W` |
| Mover para baixo | `S` |
| Mover para esquerda | `A` |
| Mover para direita | `D` |
| Dash | `Espaço` |

## 🛠️ Tecnologias

- **Engine:** Godot 4.7
